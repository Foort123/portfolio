# Little Barista — сайт мобильного кейтеринга

Чистый HTML/CSS/JS. Без сборки, без npm, без фреймворков и без WordPress.
Открывается двойным кликом по `index.html`, публикуется копированием папки на любой хостинг.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная — развилка на три сценария |
| `kino.html` | Питание съёмочных групп + калькулятор смены |
| `events.html` | Кейтеринг на мероприятиях |
| `promo.html` | Рекламные акции и BTL |
| `gallery.html` | Галерея проектов: задача → решение → результат |
| `blog.html` | Блог, четыре категории |
| `style.css` | Вся вёрстка и дизайн-система |
| `main.js` | Вся логика |
| `robots.txt`, `sitemap.xml` | SEO-обвязка |

## Что править

**Контакты и цены — только в начале `main.js`.**
Телефон, WhatsApp, Telegram и почта подставляются на все страницы автоматически
через `data-contact`, менять их в HTML не нужно.

```js
const CONTACT = { phone, whatsapp, telegram, email };
const RATES   = { breakfast, lunch, dinner, lunchbox, overtime, region, minimum };
```

**Палитра, шрифты, скругления и тени** — блок `:root` в начале `style.css`.
Весь облик сайта меняется оттуда, правки по отдельным блокам не нужны.

**Фотографии.** Сейчас на месте снимков стоят заглушки:

```html
<div class="ph ph--wide" data-label="Подпись"></div>
```

Меняются на `<img src="images/foto.jpg" alt="описание" loading="lazy">` без правки CSS.
Пропорции задаёт модификатор: `ph--wide` 16:9, `ph--square` 1:1, `ph--tall` 3:4, `ph--cine` — первый экран.

**Видео в первом экране.** В `index.html` рядом с `.hero__stage` лежит закомментированная разметка.
Раскомментировать и удалить заглушку:

```html
<video autoplay muted loop playsinline poster="images/hero-poster.jpg">
  <source src="images/hero.mp4" type="video/mp4">
</video>
```

**Заглушки в текстах** помечены в HTML комментарием `ЗАГЛУШКА`: цифры в блоках статистики,
отзывы, логотипы клиентов, кейсы и статьи. Их нужно заменить на реальные до публикации.

**Домен.** В `sitemap.xml`, `robots.txt` и в тегах `canonical`/`og:url` стоит `littlebarista.ru` —
заменить на боевой при выкладке.

## Заявки

Формы и калькулятор собирают данные и открывают WhatsApp с готовым текстом —
работает без сервера. Когда появится бэкенд или CRM, заменить функцию `sendLead()`
в `main.js` на `fetch(URL, { method: 'POST' })`. HTML трогать не нужно.

## Проверка расчёта

Открыть `kino.html?selftest` — в консоли браузера прогонятся проверки калькулятора.

## Если переезжать на WordPress

Структура готова к порту: шапка и подвал одинаковы на всех страницах и выносятся
в `header.php` / `footer.php`, сценарные страницы — в шаблоны, галерея и блог —
в типы записей с полями. `style.css` и `main.js` переносятся без изменений.
